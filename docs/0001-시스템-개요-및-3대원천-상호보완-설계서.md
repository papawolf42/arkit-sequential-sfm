# 0001: 시스템 개요 및 3대 원천 상호 보완 설계서

본 문서는 ARKit(VIO), COLMAP(SfM), Depth Anything 3(AI Depth)의 장점을 결합하여 실내 대형 홀의 기하학적 정밀 복원과 3DGS 고화질 렌더링을 달성하기 위한 기본 아키텍처를 정의한다.

---

## 1. 배경 및 문제 정의

스마트폰 비디오 스트림(iPhone ARKit)으로 촬영된 240장의 실내 사진은 다음과 같은 복합적 문제를 안고 있다:
1. **바닥 카펫 및 흰 벽의 무텍스처성:** 전통적인 SIFT 특징점 매칭이 실패하여 COLMAP SfM 복원 시 궤적이 10개의 파편화된 컴포넌트로 분열됨.
2. **단안 AI 깊이 추정의 척도 및 환각 오차:** Depth Anything 계열 모델을 맹신하여 손실을 걸 경우, 텍스처 없는 영역에서 허위 벽면이 형성되어 사중벽·오중벽(겹벽) 및 허공 부유물 발생.
3. **순수 VIO의 장거리 누적 드리프트:** ARKit은 인접 프레임 간 상대 이동은 매우 정밀하지만, 120초에 걸쳐 이동하면서 회전 오차가 서서히 누적되어 루프가 닫히지 않음.

## 2. 3대 원천 정보의 역할 분담 매트릭스

| 원천 기술 | 핵심 역할 | 주입 단계 | 시스템적 의의 |
| :--- | :--- | :--- | :--- |
| **ARKit (VIO)** | 카메라 초기 자세, 절대 미터 단위 이동량, 연속 상대 모션 | 매칭 쌍 후보 선정, Local BA 초기값 | 전체 검색 공간 축소, 스케일 모호성 제거 |
| **COLMAP (SfM)** | 다각도 특징점 기반 삼각측량, 번들 조정 | 3D 희소점 생성, 자세 재투영 오차 최소화 | 물리적 기하학의 최종 앵커(Ground Truth 역할) |
| **DA3 (AI Depth)** | 무텍스처 벽면/바닥의 픽셀별 고밀도 깊이 후보 | 무텍스처 기하 초기화, 3DGS 깊이 손실 | 특징점 없는 빈 공간의 기하학적 뼈대 형성 |

## 3. 핵심 설계 원칙: 다구간 신뢰도 게이팅 (Multi-Cue Uncertainty Gating)

**"깊이 정보가 서로 충돌할 때, 어느 데이터를 얼마나 신뢰해야 하는가?"**

어느 한 데이터를 무조건 정답으로 취급하지 않고, 물리적 관측 조건에 따라 신뢰도 가중치를 동적으로 조율한다:

```
                          [ 픽셀 / 포인트 관측 ]
                                     │
           ┌─────────────────────────┼─────────────────────────┐
           ▼                         ▼                         ▼
   [ 조건 1: 특징점 관측 ]   [ 조건 2: 무텍스처 평면 ]  [ 조건 3: 급회전/모션 ]
   다시점 삼각측량 각도       다시점 투영 깊이 일치      ARKit 회전 각속도
   θ_parallax ≥ 2.0°         ΔD_consistency < 5%       Δθ > 20°/frame
           │                         │                         │
           ▼                         ▼                         ▼
    COLMAP 기하 100% 신뢰       DA3 깊이 보조 채택       ARKit 모션 제약 완화
   (AI Depth 가중치 = 0)     (신뢰 마스크 M_valid=1)    (SfM 특징점 관측 우선)
```

## 4. 수학적 정식화: 통합 팩터 그래프 (Factor Graph Formulation)

전체 최적화 문제는 다음 4대 손실의 가중합으로 구성된다:

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{reproj}} + \lambda_A \mathcal{L}_{\text{ARKit}} + \lambda_D \mathcal{L}_{\text{depth}} + \lambda_C \mathcal{L}_{\text{consistency}}$$

1. **재투영 손실 ($\mathcal{L}_{\text{reproj}}$):**
   $$\mathcal{L}_{\text{reproj}} = \sum_{(i, k) \in \text{tracks}} \rho\left( \frac{\|x_{ik} - \pi(K_i, T_i, X_k)\|^2}{\sigma_{\text{px}}^2} \right)$$
   - $\rho$: Cauchy 견고 손실 함수 (이상치 배제)
   - $X_k$: 3D 공간 점, $x_{ik}$: $i$번째 이미지에서의 2D 특징점 관측

2. **ARKit 상대 모션 손실 ($\mathcal{L}_{\text{ARKit}}$):**
   $$\mathcal{L}_{\text{ARKit}} = \sum_{i=1}^{N-1} \| \text{Log}( (T_i^{-1} T_{i+1}) \cdot \Delta A_i^{-1} ) \|_{\Sigma_{A, i}}^2$$
   - $\Delta A_i = A_i^{-1} A_{i+1}$: ARKit이 측정한 프레임 $i \to i+1$ 간의 상대 변환
   - $\Sigma_{A, i}$: 급회전 구간에서 공분산을 크게 하여 영향력 감소

3. **DA3 자세 조건부 깊이 손실 ($\mathcal{L}_{\text{depth}}$):**
   $$\mathcal{L}_{\text{depth}} = \sum_{i} \sum_{(u, v) \in M_{\text{valid}, i}} \left| z_i(u, v) - D_{\text{DA3}, i}(u, v) \right|$$
   - $M_{\text{valid}, i}$: 다시점 일관성 검증을 통과한 신뢰 픽셀 영역

4. **다시점 깊이 일관성 손실 ($\mathcal{L}_{\text{consistency}}$):**
   $$\mathcal{L}_{\text{consistency}} = \sum_{(i, j) \in \text{covisible}} \sum_{u, v} \left| D_j(\pi(T_j, \pi^{-1}(T_i, u, v, D_i))) - D_j(u', v') \right|$$
   - 카메라 $i$의 깊이로 투영한 3D 점이 인접 카메라 $j$의 깊이 맵과 일치하도록 상호 정합
