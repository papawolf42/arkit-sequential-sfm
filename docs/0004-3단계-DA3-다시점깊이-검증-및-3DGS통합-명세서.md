# 0004: 3단계 — DA3 다시점 깊이 검증 및 3DGS 통합 명세서

본 문서는 **2단계에서 확보된 단일 통합 3D 기하 구조**를 바탕으로, **Depth Anything 3(DA3)의 자세 조건부 깊이 추정**을 안전하게 교차 검증하고 최종 3DGS(3D Gaussian Splatting) 학습에 결합하는 상세 규격을 정의한다.

---

## 1. 개요 및 설계 철학

- **문제점:** 단안 AI 모델이 추정한 깊이(Depth)를 그대로 가우시안 손실로 쓰면, 텍스처 없는 흰 벽이나 카펫에서 허위 깊이가 학습되어 **사중벽·오중벽(겹벽)과 허공 부유물**이 발생함.
- **해결책 (Depth Consistency Gating):**
  1. 단일 시점 깊이를 그대로 믿지 않고, **인접 카메라 시점으로 재투영했을 때 깊이가 상호 일치하는 픽셀($M_{\text{valid}}$)**만 마스킹하여 채택.
  2. 기하학적으로 검증된 마스크 영역에만 가우시안 표면 밀착 깊이 정규화 손실 주입.

---

## 2. DA3 자세 조건부 다중시점 추론 파이프라인 (`tools/infer_da3_pose_conditioned.py`)

### ① 입력 및 호출 방식
Depth Anything 3는 카메라 내부 파라미터($K$)와 6DoF 자세($T$)를 직접 입력받아, 카메라 이동량에 정합된 미터 단위 역깊이를 직접 출력합니다:

```python
# 개념적 Python API 호출
import depth_anything_3 as da3

model = da3.load_model("da3-small") # Apache 2.0 라이선스 모델 우선 사용
depth_maps = []

for batch_frames in sliding_window_batches(frames, window_size=5):
    # 인접 5장의 이미지와 2단계에서 보정된 카메라 자세(T) 주입
    depths, confidences = model.infer(
        images=[f.image for f in batch_frames],
        extrinsics=[f.c2w for f in batch_frames],
        intrinsics=[f.K for f in batch_frames]
    )
    depth_maps.extend(depths)
```

## 3. 다시점 깊이 일관성 검증 모듈 (`tools/filter_depth_consistency.py`)

### ① 픽셀별 기하 일관성 판정 알고리즘
카메라 $i$의 픽셀 $(u, v)$에 예측된 깊이 $D_i(u, v)$가 있을 때:
1. 3D 공간 역투영:
   $$\mathbf{X} = T_i \cdot \left( D_i(u, v) \cdot K_i^{-1} \begin{bmatrix} u \\ v \\ 1 \end{bmatrix} \right)$$
2. 인접 카메라 $j$로 재투영:
   $$\begin{bmatrix} u' \\ v' \\ 1 \end{bmatrix} \sim K_j \cdot T_j^{-1} \cdot \mathbf{X}, \quad z_j = (T_j^{-1} \cdot \mathbf{X})_z$$
3. 카메라 $j$의 DA3 예측 깊이 $D_j(u', v')$와 투영 깊이 $z_j$ 비교:
   $$\text{Relative Error} = \frac{|z_j - D_j(u', v')|}{\max(z_j, D_j(u', v'))}$$
4. **신뢰 마스크 $M_{\text{valid}, i}(u, v)$ 판정:**
   - $\text{Relative Error} \le 0.05$ (5% 오차 이내)인 경우만 $1$, 불일치하는 경우 $0$ (제외).

## 4. 3DGS 렌더러 결합 손실 함수 (`experiments/loss.py`)

최종 3DGS 학습 시, 래스터라이저의 기대 깊이($D_{\text{render}}$)와 검증된 DA3 깊이($D_{\text{DA3}}$)를 정합:

$$\mathcal{L}_{\text{3DGS}} = 0.8 \mathcal{L}_1 + 0.2 \mathcal{L}_{\text{DSSIM}} + \lambda_{\text{depth}} \sum_{(u, v) \in M_{\text{valid}}} \left| \frac{1}{D_{\text{render}}(u, v)} - \frac{1}{D_{\text{DA3}}(u, v)} \right|$$

- **효과:**  
  - $0.8 L_1 + 0.2 \text{DSSIM}$: 가구 모서리 및 글씨의 쨍한 선명도 복원.
  - $M_{\text{valid}}$ 역깊이 정규화: 텍스처 없는 벽면/바닥에 가우시안들이 자석처럼 밀착되며, 불일치 영역의 사중벽/오중벽 발생 원천 차단.
